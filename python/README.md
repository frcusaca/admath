# vecdraw

The drawing library for the linalg-circle course. The drawing code in
`src/vecdraw/__init__.py` is written for 10-year-olds to read and change.

```python
from vecdraw import *

new_grid(6)
draw_vector([3, 4], label="a")
show()

explore_angles([4, 0], [3, 3], names=["a", "b"])   # the Angle Explorer, in the notebook
```

`src/vecdraw/static/angle-explorer.iife.js` is generated by `make explorer`
from `../explorer`. Do not edit it by hand.
